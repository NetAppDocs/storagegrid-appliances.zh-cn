= SG6000、SG6100 和 SG6200 StorageGRID 设备和服务设备的 BMC 接口
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
基板管理控制器 (BMC) 的用户界面提供有关硬件的状态信息，并允许对设备配置、监控和诊断进行低级硬件访问。

您可以使用 BMC 执行以下操作：

* 对硬件安装进行故障排除
* 配置SNMP设置
* 确定设备的电源状态
* 控制设备上的标识 LED


以下 StorageGRID 设备支持 BMC 接口：

* SG100
* SG110
* SG120
* SG1000
* SG1100
* SG1200
* SGF6024
* GF6112
* SGF6212
* SG6060
* SG6160
* SG6260


如果要安装设备，请使用以下过程配置 BMC：

* link:../installconfig/changing-root-password-for-bmc-interface.html["更改BMC界面的管理员或root密码"]
* link:../installconfig/setting-ip-address-for-bmc-management-port.html["设置 BMC 管理端口的 IP 地址"]
* link:../installconfig/accessing-bmc-interface.html["访问 BMC 界面"]
* link:../installconfig/configuring-snmp-settings-for-bmc.html["配置SNMP设置"]
* link:../installconfig/setting-up-email-notifications-for-alerts.html["为BMC警报设置电子邮件通知"]


如果您已将设备安装到网格中，并且它正在运行 StorageGRID 软件，请使用以下过程：

* link:../commonhardware/placing-appliance-into-maintenance-mode.html["将设备置于维护模式"] 以访问StorageGRID设备安装程序。
* 有关使用 StorageGRID 设备安装程序访问 BMC 接口的信息，请参阅 link:../installconfig/setting-ip-address-for-bmc-management-port.html["设置 BMC 管理端口的 IP 地址"]。


要了解有关配置 BMC 后可以使用哪些功能的详细信息，请参阅 link:../commonhardware/use-bmc.html["使用BMC界面"] 和  https://kb.netapp.com/hybrid/StorageGRID/Platforms/How_to_use_StorageGRID_Appliance_BMC_with_vendor_supplied_user_guide["《BMC用户指南》"^]。
